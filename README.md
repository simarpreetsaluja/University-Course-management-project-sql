# 🎓 University Course Management System (SQL)

## 📌 About the Project
The University Course Management System is a simple SQL project that helps manage university information in one place.

It stores details about students, teachers, departments, courses, and student registrations. SQL queries are used to add, view, update, and manage this information.

## 🎯 Project Goals
- To store university information in a database.
- To manage student and teacher details.
- To keep records of courses and departments.
- To check which students have joined which courses.
- To learn and practice SQL queries.
- To find useful information from the database.

## 🗂️ Database Tables

This project uses five main tables:

| Table Name | What It Stores |
|---|---|
| `Department` | Department names and IDs |
| `Students` | Student details and joining dates |
| `Courses` | Course names, credits, and department details |
| `Instructors` | Teacher details and salary information |
| `Enrollments` | Records of students registered for courses |

## 🔗 How the Tables Are Connected
- One department can have many courses.
- One department can have many teachers.
- One student can join multiple courses.
- One course can have many students.
- The `Enrollments` table keeps track of students and their courses.

## 🛠️ Technologies Used
- SQL
- Relational Database
- Primary Keys and Foreign Keys
- SQL Joins
- Aggregate Functions
- Subqueries

## 📚 What I Learned
- How to create and manage database tables.
- How to add, update, delete, and view records.
- How to connect tables using SQL Joins.
